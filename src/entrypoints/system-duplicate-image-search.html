Managing Duplicates — Your Safe Options

After finding duplicates, you have three ways to handle them:

📋 Copy File Name

Copies the full filename to your clipboard. Nothing is changed on your computer.

Use this when you want to track files manually without making any changes yet.

📁 Move to Duplicates Folder

Creates a folder called PixDuplicate-Duplicates and moves the duplicate there. The file is NOT deleted — just relocated.

✓ SAFE: Files are moved, not deleted. You can review and restore them later.

Location: YourSelectedFolder/PixDuplicate-Duplicates/

Requires Chrome 86+, Edge 86+, or Safari 15.2+

🗑 Delete Permanently

Removes the file completely. This action cannot be undone.

⚠ WARNING: File will be gone forever — does NOT go to Recycle Bin or Trash.

We strongly recommend using Move first so you can review before deleting.

Requires Chrome 86+, Edge 86+, or Safari 15.2+
